# AGENTS.md — Правила проекта: Поиск партнеров dGAG

## 0. Цель и образ результата
Исследуем доместицированный ретротранспозонный белок GAG (dGAG) в Arabidopsis thaliana. 
Наша задача — предсказать белки-партнеры dGAG и его возможную функцию.
В конце работы в проекте существуют:
- `results/candidates.csv` — таблица с кандидатами (столбцы: `gene_id, protein_name, evidence_type, source`);
- `reports/summary.md` — краткое описание функции и список партнеров.

## 1. Критерий готовности
Работа считается выполненной, когда проходит проверка:
`python checks/check.py`
Вызови проверку сам перед тем, как дать окончательный ответ. Ответ без пройденной проверки не принимается.

## 2. Карта проекта и источники
- Данные: `data/dGAG_fasta.txt` — последовательность белка.
- Чего агент не может знать сам: dGAG относится к ретротранспозонам, поэтому искать нужно через базы данных белковых взаимодействий (STRING, UniProt, BioGRID) или по гомологии с известными GAG-белками.

## 3. Инструменты и границы
- Используй Python 3 для парсинга данных и запросов к API (например, библиотеки `requests` или `biopython`).
- Для веб-поиска используй встроенный инструмент `web_search`, если нужно найти статьи.

## 4. Запреты
1. Не изменять исходные данные в `data/`. [среда] (папка закрыта от записи).
2. Не менять код проверки `checks/check.py`. [среда].
3. Не выдумывать гены-партнеры, если их нет в базе данных. Указывать источник (ссылку или ID). [окно]

## 5. Протокол работы
Режим работы: ReAct. 
1. Прочитай данные и цель.
2. Найди информацию о dGAG в базах данных или через веб-поиск.
3. Сформируй список 3–5 кандидатов в белки-партнеры.
4. Запиши результат в `results/candidates.csv`.
5. Запусти проверку `python checks/check.py`. Если код 0 — задача решена.
